# 06 · Make the selected keyframe’s Value and Interp controls commit

**Status:** Proposed · **Last verified against:** `7b320b3`  
**Supersedes / Superseded by:** none · **Related finding:** [reactivity audit, “Several keyframe controls silently do nothing”](../2026-11-23-cljfx-reactivity-audit.md#L60). [01](01-numeric-commits.md) owns numeric text Enter.

## 1. Current behaviour

**A spinner step or a dropdown selection can change the widget without changing the keyframe.** Rechecked in a fresh headless JVM at `7b320b3`: mounted the three native descriptions from the real panel’s actions row, recorded the existing function listeners’ inputs/returns, and counted events at cljfx’s map dispatcher. No app, services or devices were started. Source paths below are relative to `src/laser_show/` except where marked; **panel** means `views/components/visual_editors/keyframe_modulator_panel.clj`.

| Control | What actually changes | Existing listener result | Dispatched |
|---|---|---|---:|
| Zone Value (`panel:418–436`) | JavaFX `ComboBox`; its new item is a Clojure map, e.g. `{:id :auto/left :kind :auto :name "Left" …}` | `:keyframe/update-param` with `:value :auto/left` | 0 |
| Numeric Value (`panel:438–449`) | JavaFX `Spinner` with `SpinnerValueFactory$DoubleSpinnerValueFactory`; one increment from `0.5` delivers `java.lang.Double` `0.6` | `:keyframe/update-param` with `:value 0.6` | 0 |
| Interp (`panel:91–103,451–464`) | JavaFX `ComboBox`; “Ease In” is the keyword `:exp-grow`. The other items are `:linear`, `:exp-decay` and `:step` | `:keyframe/set-interpolation` with `:interpolation :exp-grow` | 0 |

The shared editor passes the effect definition, full relative effect path and modulator (`views/components/effect_parameter_editor.clj:43–52,138–154,223–232`). The panel takes the supplied parameter key or the **first parameter in the definition**, looks up its `:type`, and puts the selected zero-based index and actual parameter key in the Value template (`panel:498–521,588–601`). It shows the actions only when enabled, with a valid selection; Interp is hidden for `:zone-group-id` (`panel:398–419,452–464,535–538`). A Zone Selector’s parameter is **`:target-zone`**, not `:zone-group-id`: the latter is its *type*. The effect is registered but hidden from the bank; old cue selectors are migrated away (`animation/effects/zone.clj:5–10,46–63`; `state/migration.clj:220–231`). Test an existing instance, not a bank click or a routing outcome.

**A type trap in the same Value branch:** the actual test at `panel:418–449` is *zone versus everything else*. `:numeric` in the row’s docstring is not the effect registry’s numeric type. Intensity declares `:float`, Decimate’s first parameter `:int`, Blackout `:bool`, and Zone pattern starts with `:choice` (`animation/effects/intensity.clj:20–31,42–51`; `animation/effects/points.clj:32–36,108–114`; `routing/zone_patterns.clj:73–81`). In the same headless check, the current factory with an integer `25` produced **`25.1`** on increment; mounting it with `:alternate` produced `ClassCastException`. Just enabling dispatch on that catch-all would write values of the wrong type.

## 2. Root cause and pinned API

- In **cljfx 1.10.6** (`deps.edn:12–16`; JavaFX controls `28-ea+11` on this platform, `deps.edn:107–114`), a [map installed as the handler](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/lifecycle.clj#L152-L200) calls `:fx.opt/map-event-handler` with `:fx/event` added. A function installed there is simply called. The [change-listener adapter](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/lifecycle.clj#L212-L213) passes [only the **new value**](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/coerce.clj#L482-L493) to the function; JavaFX does nothing with its return. There is no `ActionEvent`, source node, old/new pair, or automatic dispatch of the returned map.
- [Spinner props](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/fx/spinner.clj#L17-L32): `:value-factory` is on the spinner; `:value`, `:min`, `:max` and `:amount-to-step-by` belong on the [double](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/fx/double_spinner_value_factory.clj#L10-L24) or [integer](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/fx/integer_spinner_value_factory.clj#L10-L24) factory. **`Spinner` itself supports `:on-value-changed`** and is non-editable by default. The [factory also supports a listener](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/fx/spinner_value_factory.clj#L10-L15); install only the spinner listener. Both dropdowns inherit [`ComboBoxBase`’s `:on-value-changed`](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/fx/combo_box_base.clj#L19-L27).
- Replacing the three listeners **in memory** with recorder maps gave exactly three events: `0.6`, `:exp-grow`, and the **whole** zone option. Advancing the descriptions to different values and deleting the components left the count at three. cljfx [suppresses synchronous callbacks during root create/advance/delete](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/lifecycle.clj#L57-L70) and advances the installed handler to its new description. Use that lifetime instead of attaching a second native listener.

## 4. Changes per namespace

1. **Panel** (existing namespace, `panel:1,385–403,418–464,513–521,588–601`): install the three **map** handlers in §6. Keep the address in the render-time template: `:domain`, `:entity-key`, full `:effect-path`, `:keyframe-idx`, and `:param-key` for Value. Do not send a rendered keyframe/vector or replace the addressed index with whichever frame happens to be selected later. Keep the existing guard on selection and the zone-only/no-Interp layout. Make Interp’s display function tolerate an empty cell (no call to `name` on nil, `panel:95–103`).
2. Pass the already-resolved descriptor (`panel:513–515`) to the actions row as **NEW here**, view-only `:param-spec`. Add one **NEW private** `numeric-value-factory [param-spec stored-value]` in the panel: it chooses the native factory once, separately from event wiring. For `:float` use `:double-spinner-value-factory`, step `0.1`; for `:int` use `:integer-spinner-value-factory`, step `1` (in the probe `25 → 26`, boxed `Integer`). Use declared bounds, with the existing `-9999..9999` span for missing bounds; use the descriptor default for a missing value, otherwise typed zero. Only construct a numeric factory for a numeric descriptor and finite numeric input. An omitted type with a numeric default follows the editor’s existing `:float` convention (`views/components/modulator_param_control.clj:625–638`). Explicit nonnumeric types get no numeric Value widget; their parameter controls and the non-zone Interp control remain available. Never write a default or coerce stored data on render. The separate **Period** spinner already dispatches its map (`panel:219–226,560–567`); it is not the Value editor.
3. **`laser-show.events.handlers.keyframe`** (`events/handlers/keyframe.clj:1,462–475,497–520`): extend the existing zone route to extract an option ID and the interpolation writer to accept only a supported mode (§6). Treat an absent/invalid payload, missing frame, or non-integer/out-of-range index as no edit. Keep the generic parameter writer compatible with other callers, including nonnumeric parameter controls (`views/components/effect_parameter_editor.clj:169–179,279–287`; `views/components/parameter_controls.clj:147–155,165–175`). Integrate with 01’s typed-input boundary; do not make every `:keyframe/update-param` a numeric-only command or parse text in this row.

## 5. State placement and refresh

Let `K` denote `chain-config`’s **existing** items path + `effect-path` + `[:keyframe-modulator]` (`events/handlers/chain/helpers.clj:34–39`; `events/handlers/keyframe.clj:37–51`). For Effects cell `[0 0]`, path `[0]`, `K` is `[:chains :effect-chains [0 0] :items 0 :keyframe-modulator]`; a cue item’s effect uses e.g. `[0 :effects 0]` relative to its items root (`views/dialogs/cue_chain_editor.clj:60–81`; `views/components/effect_parameter_editor.clj:43–52`).

| Existing path | Owner, writer and reader | Undo / dirty |
|---|---|---|
| `K + [:keyframes i :params k]`, `K + [:keyframes i :interpolation]` (`events/handlers/keyframe.clj:315–322,369–376`) | Show document for these cue/effect editors; the keyframe handler returns `:state`. Saved with the chains (`state/persistent.clj:81–86,138–147`). In the Effects dialog the `:chains` and list-selection subscriptions deliver the selected effect to the editor (`views/dialogs/effect_chain_editor.clj:47–64,83–96,154–160`). The panel renders that frame; the parameter section reads the same frame’s params (`views/components/effect_parameter_editor.clj:143–154`). | One discrete changed value → one undo snapshot; dirty against the saved baseline (`events/handlers/history.clj:272–275,299–324,369–393`; `state/history.clj:173–206,349–366`). No explicit transaction or dirty flag in these controls. |
| `K + [:selected-keyframe]` (`events/handlers/keyframe.clj:190–209`; `panel:498–503`) | Existing **live editor selection**, physically inside the saved chain. Timeline selection writes it; Value/Interp edits do not. The same subscriptions feed the row label, controls and timeline (`panel:398–415,569–600`). | Selection alone is neither undoable nor dirty. Keep current restore policy: unchanged frames keep current selection on a uniquely identified item; changed frames use the snapshot selection, clamped to range (`state/history.clj:52–55,101–117,215–248`). |

**No new persisted path, UI state key or runtime atom.** The new row prop and native payloads last only for a render/event. The existing context commit drives refresh, including Undo/Redo. Do not remount the window, reread the global state in a listener, or enqueue a synthetic refresh (`events/core.clj:15–27,165–173`; `docs/CLJFX_STATE_MANAGEMENT.md:5–13`).

## 6. Events and effects

| Existing event | Native dispatcher → handler contract (proposed changes) |
|---|---|
| `:keyframe/set-zone-value` | **New producer, existing event.** Choose this event for the zone branch of the Value template at `panel:588–598`; install it on the combo at `panel:428–436`. `:fx/event` is the option map. Today `events/handlers/keyframe.clj:511–515` blindly chooses `:value` or `:fx/event`; installing the map without changing that branch would store the **entire option**. Extract its keyword `:id` in the pure handler. Preserve a directly supplied keyword `:value` and the existing raw keyword form. Nil/absent/ill-typed ID → no edit, **not** a fallback write of `:all`. |
| `:keyframe/update-param` | On the **outer spinner** at `panel:443–449`, install the Value template from `panel:595–598` with `:value :fx/event`. The app supplies the resulting scalar to `handle` (`events/core.clj:607–621`; `events/handlers/keyframe.clj:497–501`, `first-some` at `events/helpers.clj:50–54`). A step sends an absolute finite number, including zero; no text read, delta calculation or second dispatch. |
| `:keyframe/set-interpolation` | On the combo at `panel:457–464` install its template (`panel:599–601`) with **`:interpolation :fx/event`**. The existing branch reads `:interpolation` **only** (`events/handlers/keyframe.clj:517–520`); merely installing the bare template would write nil. After substitution validate against `interpolation-fns` (`animation/interpolation.clj:12–21`); an explicit valid `:interpolation` remains supported. |

All three use the [pinned `create-app` map dispatcher](https://github.com/cljfx/cljfx/blob/1.10.6/src/cljfx/api.clj#L596-L614) → the app’s ordered pipeline (`app.clj:95–112`; `events/core.clj:628–653,669–679`) → `"keyframe"` router (`events/handlers.clj:31–44,71–75`). Handlers are pure. **Only existing effect required: `:state`**, registered in `events/core.clj:719`, committed at `:165–173` there. No new event, effect, follow-up `:dispatch` (existing, `events/core.clj:175–178,720`), async work or I/O.

## 7. Data examples and invariants

Common event address for these examples: `{:domain :effect-chains :entity-key [0 0] :effect-path [0] :keyframe-idx 1}`. The fragments show the **delivered** payload after cljfx has attached its value and before app placeholder substitution. Outputs are changes relative to `K` above.

| Before + delivered input | Expected output |
|---|---|
| Zone frame 1 `:all`; `{:event/type :keyframe/set-zone-value :param-key :target-zone :fx/event {:id :auto/left :name "Left" :kind :auto}}` | `[:keyframes 1 :params :target-zone] → :auto/left`; existing `:interpolation :step` stays. |
| Float frame 1 amount `0.5`; `{:event/type :keyframe/update-param :param-key :amount :value :fx/event :fx/event 0.6}` | `[:keyframes 1 :params :amount] → 0.6`; base `[:params :amount]` on the effect stays `1.0`. |
| Integer frame 1 `{:kpps 25 :fps 30}`; one Value increment | Frame params `{:kpps 26 :fps 30}`; `26` is integral. |
| Frame 1 `:linear`; `{:event/type :keyframe/set-interpolation :interpolation :fx/event :fx/event :exp-grow}` | `[:keyframes 1 :interpolation] → :exp-grow`; params and frame 2’s mode stay as they were. |
| Zone option `nil` or `{:name "Left"}`; Interp `:unknown`; valid value sent to index `3` of three frames | No document change or undo entry; an existing Redo remains available. |

For each accepted edit: one addressed leaf, one delivered intent, one undo step. Index, positions, sibling frames/params, base params and other cells stay intact. A render, a selection-only change and a repeated equal value do not create an edit or clear Redo. The timeline is fed the resulting vector; its zone segments read each frame’s ID (`panel:569–579`; `views/components/visual_editors/keyframe_timeline.clj:185–207,268–285`).

## 9. Scope
