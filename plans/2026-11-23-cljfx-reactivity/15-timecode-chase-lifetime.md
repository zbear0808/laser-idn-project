# 15 — End timecode chase when its cue stops following

**Status:** Implemented in `6bfb56e` on `reactivity/integration` (2026-11-24); see [implementation status](00-overview.md#implementation-status-2026-11-24). Planned as: Proposed · **Last verified against:** `7b320b3` (2026-11-23; source and test fixtures inspected).

**Supersedes / Superseded by:** none · **Related findings:** [Follow Timecode Off → duplicate run](../2026-11-23-cljfx-reactivity-audit.md#L89), [Stop → cleanup](../2026-11-23-cljfx-reactivity-audit.md#L86). Paths below are relative to `src/laser_show/`; `T/` means `test/laser_show/`.

## 1. Current behaviour

1. **Follow Timecode** dispatches `:timeline/apply-op` with `{:op :set-chase :source :mtc}` or `{:op :set-chase :source nil}` (`views/components/visual_editors/timeline/inspector.clj:18–19,180–198`). The handler edits the current cue at `[:chains :cue-chains [col row]]`; Off removes `:timeline/chase` and the undo label is “Set Follow Timecode” (`events/handlers/timeline.clj:119–160,531–532`; `timeline/model.clj:681–683,695–707,739–742`). It changes neither a chase intent nor clock memory.
2. The MIDI receiver sends quarter-frame `:data1` and full-frame SysEx `:data` directly to the decoder (`input/midi.clj:93–113,122–132`; `input/mtc.clj:210–226`). The **60 Hz `show-clock` thread** reads one app snapshot and `mtc/current`, calls pure `show-time/step`, publishes positions and, **only if** `[:playback :playing?]`, rendered cues; it dispatches reports *after* publishing (`services/show_clock.clj:1–7,68,258–304`). A following timeline inside its half-open window takes its beat from MTC, including freewheel; stopped MTC, even at a known time, is inactive (`timeline/playback.clj:17–21,53–99`; `input/mtc.clj:152–176`).
3. Ordinary intents have a `:run` ID. `reconcile-runs` rebuilds `:runs` from those intents, excluding followers. In contrast, `chase` seeds `apply-chase` with **all** of the last `:chase` map. That reduce visits current cue definitions, skipping non-followers. `pending-reports` also visits only definitions that *still* follow (`animation/show_time.clj:141–145,168–180,201–205,227–235`; `timeline/playback.clj:73–101`). On writes `{:chasing? true :timeline? true}` and opens the transport; Off removes whatever intent is there if the cue follows **or** the intent says chasing (`events/handlers/timing.clj:168–183`). Neither report identifies the owner it observed.
4. Grid Clear removes both definition and intent, whereas Paste replaces the definition; Move can transfer the intent to a different cell (`events/handlers/grid.clj:133–155,166–187`; `events/helpers.clj:121–134`). Undo/Redo prune intents for *absent* cells, not changed definitions or clock entries (`events/handlers/history.clj:65–83`; `state/history.clj:295–315`; compare [improvement review 02](../2026-11-07-improvement-review/02-events-state.md#L261)). New and successful Open reset app playback, not the running show clock (`state/persistent.clj:193–206,243–255,257–271`; clock reset on **clock start** at `services/show_clock.clj:338–351`). A cell address can be occupied again before a queued report lands.

## 2. Root cause

The old map answers “what played last tick?”, not “which definition owns this timing now?”. Removing the definition skips the only branch that could remove its timing. `positions` merges chase *after* ordinary run positions; `active-runs` emits ordinary intents, then appends unacknowledged chases using the **current** chain at each address (`animation/show_time.clj:294–324`). Thus Clear can leave a phantom position even with nothing to draw; replacing or manually restarting the cue can draw it at the old beat, or draw it twice. The audit reproduced the duplicate on synthetic ticks. Filtering duplicates in the view would still leave the wrong clock position and the wrong report recipient.

There is also a legitimate Off for a **manual** owner: turn Follow on while a manual timeline plays and MTC is stopped. The clock must stop *that* run (`T/animation/show_time_test.clj:420–431`). “Only remove if chasing” breaks this case; “remove the cell” can kill its successor.

## 4. Implementation steps

1. **Give each followed definition a local version.** In `laser-show.events.handlers.timeline` (`events/handlers/timeline.clj:1,477–501`), add **NEW** pure `reconcile-chase-sources [before after]` to the changed-cue boundary, after the handler's final normalized **or restored** state. Declare the session field in `state/domains.clj:57–85` (§5). Within the same document, skip identical cue maps. For changed cells assign the next integer to each new/changed follower; remove a version when its cue disappears or stops following. Never rewind the counter on Undo or on removing the last entry. Even a new, value-equal cue at that address gets a fresh version. This is a *version*, not a saved cue UUID: cue roots need not have IDs (`state/templates.clj:19–36`). Check replacement of the document before the identity fast path; its initial followers have version 0, distinct from the old show's by #20's stamp. An edit to a different cell leaves this version alone.
2. **Release old control of a cell.** When a definition becomes absent/non-following, remove only its still-present **chase** marker in that same event result. The next grid toggle/editor Play must work even before another tick (grid counts any intent as active at `events/handlers/grid.clj:109–129`; editor Play/resume and toggle at `events/handlers/timeline.clj:379–413`). Preserve a manual intent written by the intervening command. At the two eager deletion sites (Clear at `events/handlers/grid.clj:178–187`; restore pruning at `events/handlers/history.clj:65–83`), use #03's removal on the matching chase marker **while it still exists**, so a real last removal closes the gate once. A moved intent is not an end at its destination. For follower → follower revisions, keep the marker until the next sample can rebind or retire it; an edit in a running timeline need not insert a blank tick.
3. **Reconcile before publishing.** In `laser-show.animation.show-time` (`animation/show_time.clj:1,168–205,260–283`), seed the chase only with timings whose **document, cell and current source version** still match; then apply the existing timecode calculation to current followers. Reuse timing and episode ID across in-window running/freewheel/locates. On first entry, re-entry after a stop/range exit, or replacement, start fresh at the *current absolute MTC beat*. **NEW** `:chase-id` is `[document-id cell source-version clock-origin-ns entry-tick]`, fixed for that episode. Supply the already-computed monotonic origin to the first step as well as later ones (`services/show_clock.clj:266–273,285–286`; runtime `:t0-ns`, `:tick` at `animation/show_time.clj:42–54`). No UUID generation or clock read inside `step`. The first tick of a new show uses none of the old show's chase timing or retry keys, even for identical cue data. Do not reset the decoder or the global clock on a document edit.
4. **Report a conditional transition.** Extend the chase branch of `pending-reports` (`animation/show_time.clj:210–235`). Reconcile the union of desired chase cells, app chase markers **including orphan markers**, and manual intents at currently following definitions. At most one chase decision per cell: On if an active episode lacks its matching marker; Off if no episode is desired and there is an old chase marker, or a manual run to surrender to a *currently enabled* follower. No Off for an ordinary definition's manual intent, or for an already empty cell. **NEW** pure `intent-owner [intent]` in `laser-show.timeline.playback` (`timeline/playback.clj:1–14,50–56`) gives both sender and receiver one vocabulary: `:none`, `[:run r]`, `[:chase k]`; an unrecognized intent is not `:none`. Report document, current source version (`nil` = no follower), expected owner and, for On, episode ID and start authority (§6). Do not put beats, wall time, cue maps or the *current* tick number into retry keys.
5. **Check both ends of the handoff.** `handle-show-clock-chase` (`events/handlers/timing.clj:168–183,299–302`) requests the existing clock-read effect. Extend `effect-show-clock-read` (`events/core.clj:299–309`) for **NEW** `:chase-cell`: one read of `!runtime` supplies `:clock {:chase-id K}` or `:clock {:chase-id nil}` for that cell. Continue inline to **NEW** `:show-clock/apply-chase`, in the existing timing router. Its pure handler requires the report's non-nil document stamp to equal the current one, the source version to match the current cell, and the expected owner to match its actual intent. On additionally requires a current follower and the same **non-nil** episode ID in the clock observation. Off requires an explicitly observed **absent** clock episode. This rejects a late On after MTC stopped and an old Off after reacquisition even while the app marker is still catching up. Missing fields are not wildcards. A match on On installs the tagged marker; rebinding a chase marker preserves focus/gate. Off for `[:chase k]` can retire that marker even with no definition left. Off for `[:run r]` can retire only that run while the observed definition still follows. Use #03's helper for removal; on any mismatch leave state unchanged.

**An in-window acquisition can start playback from ordinary idle.** Freeze its start authority *at entry*: the observed `[:playback :requests :restart :id]` (possibly `nil`) and whether the transport was free to start (not closed with held intents). On can open a closed gate only for a genuine acquisition, with that same restart ID and no currently held intents. An On overtaken by Stop may register a still-valid **held** marker but cannot reopen the gate; retries within that episode do not acquire a new start authorization. A later Play resumes the current position. A fresh MTC entry after a real exit can again start from idle. Off only retires its owner: last actual removal closes the gate; removal with survivors preserves the gate; a duplicate cannot close a later empty Play. There is no per-tick “non-empty means Play / empty means Stop” rule. Manual grid start and timeline transport keep their existing follow checks (`events/handlers/grid.clj:35–52`; `events/handlers/timeline.clj:360–363,534–540`).

**Invariants:** after each step `:chase` contains exactly current following timelines with a running/freewheeling position in `[0, effective-length)`; its cell keys are disjoint from the cells in `:runs`. Seek/reverse, tempo edits and re-entry use the sampled beat, never elapsed local chase time. Keep existing intent order, then sorted unacknowledged chases (`animation/show_time.clj:301–324`); an occupied cell renders at most once, including before its On is acknowledged. Report retries reuse the same owner/authority and stop on agreement. No throughput improvement is claimed or needed for acceptance.

## 9. Dependencies and scope

* **#03** owns shared deactivation and Stop semantics ([03 §4, §9](03-stop-and-cue-completion.md)). Its removal contract is needed for the held/last-cue integration assertions, not to build or test the pure runtime pruning. Chase Off is not `:show-clock/cue-ended` (`animation/show_time.clj:227–235`): the latter concerns a local run's position, the former external ownership.
* **#20** owns creating/rotating the document stamp on accepted replacement ([overview](00-overview.md#L95)). Consume it for the cross-show guard/test; same-show cases can be developed with a fixed synthetic document ID. No dependency on MIDI connection/learning changes or render-cache work. Decoder thresholds, wire protocol, project format and physical output are outside this repair.
